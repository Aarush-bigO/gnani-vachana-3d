## Reporting a Vulnerability

The Gnani Vachana 3D project takes the security of sovereign AI systems, voice biometric signals, and user privacy seriously.

If you believe you have discovered a security vulnerability or exploit related to:
* PII leakage or de-anonymization
* armour365™ voice biometric bypass
* WebSocket injection or buffer exhaustion
* Concurrency guard bypass or race conditions

Please **do not** report it publicly on GitHub Issues.

Instead, please send an encrypted or direct disclosure email to:
**aarushbharti2005@gmail.com**

Please include:
1. Detailed description of the vulnerability.
2. Steps to reproduce or proof-of-concept payload.
3. Potential impact on sovereign telephony or user sessions.

You will receive an acknowledgment within 24 hours and regular status updates until the fix is deployed.
